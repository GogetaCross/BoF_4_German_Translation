# rect_tuner.txt - saved by the in-game Rect Tuner (F10).
# Universal grammar (same as rect_widths.txt); read by rect_fix/rect_tuner.
#
# ==================== HOW A LINE WORKS ====================
# This file re-skins GRAPHICS (textured rects). rect_widths.txt is for box/cursor
# widening+shifting only. F5 reloads BOTH live. First matching line wins per rect.
#
# A "# DAT.DAT (w A->B) [broad/persistent]" line is an auto-note the F10 tuner
# writes: source DAT + width A->B. [broad/persistent] = matched by u/v alone (no
# sig), so it applies to that atlas graphic EVERYWHERE it's drawn (all scenes/DATs).
#
# Each non-# line = ONE override:  <MATCH fields> <REWRITE fields>
#   MATCH (which rect to grab):
#     u= v=    atlas SOURCE pixel the game samples (the identity of the graphic)
#     clut=    palette id (use to tell two rects at the same u/v apart)
#     ow=      ORIGINAL on-screen width (further disambiguates same u/v)
#     sig=     exact draw-site signature (scopes to ONE instance, not broad)
#     mx= my=  only match when drawn at this on-screen x/y (per-instance)
#   REWRITE (what to change):
#     w= h=    new on-screen size. NOTE: PSX 0x64 rects DON'T scale — w just sets
#              how many texels are SAMPLED, so smaller w CROPS the right edge;
#              w=0 = hide it. h likewise crops vertically.
#     nu= nv=  RE-POINT to a different atlas source (sample your German art from
#              elsewhere on the sheet, e.g. a repainted region)
#     dx= dy=  relative screen NUDGE (+dx = right, +dy = down)
#     x= y=    absolute screen position (prefer dx/dy for animated sprites)
#
# Worked examples (the fishing lines below):
#   u=168 v=224 clut=0x7E0B ow=8 w=0 dx=7
#       -> grab the 8px sprite at atlas (168,224); w=0 HIDES it (+7px moot).
#   u=0 v=96 clut=0x7E08 ow=96 w=76
#       -> grab the 96px sprite at (0,96); sample only 76 texels (crops right 20).
#   u=0 v=128 clut=0x7E08 ow=160 nu=80 nv=96 w=84 h=32 dx=38
#       -> grab the 160px sprite at (0,128); instead sample your art at (80,96),
#          draw it 84x32, and shift 38px right.  (= the Fang!/Daneben! fix)
# =========================================================
