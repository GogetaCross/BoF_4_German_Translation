# rect_widths.txt - universal runtime un-clip (hook on BOF4!0x502070).
# Match a textured rect by its ORIGINAL atlas source and rewrite it. Turn on
# rect_trace + press F9 in-game to get rect_inventory.txt (every label's u/v).
#
# Per line:  u=N v=N [clut=0xN] [ow=N] [mx=N] [my=N]  [w=N] [h=N] [x=N] [y=N] [dx=N] [dy=N] [dw=N] [dh=N] [nu=N] [nv=N]
#   h     = new on-screen HEIGHT (9-slice box edges/fill); dw/dh = grow w/h by delta
#   u,v   = source to MATCH (atlas pixel coords from the inventory)
#   clut  = optional CLUT to match (use if two labels share u,v)
#   ow    = optional ORIGINAL width to match (further disambiguation)
#   mx,my = optional ON-SCREEN x/y to match — splits a tile drawn at
#           several spots (e.g. two 'pts.') into per-instance rules;
#           put mx/my lines BEFORE a catch-all line for the same u/v
#   w     = new on-screen width (un-clip)
#   x,y   = optional new ABSOLUTE screen position
#   dx,dy = optional RELATIVE nudge (dx=-4 = 4px left, dy=2 = 2px down);
#           preferred over x/y for runtime-positioned labels
#   nu,nv = optional new atlas source (relocate a repainted/widened graphic)
#
# GLOBAL directive lines (no caller=/u=): e.g. `equip_menu_shift = N` shifts the
# whole equipment-skill "Menü" (box+labels+title+cursor) left N px. F5-live.
#
# COVER-THE-GAP (menu box widen): when a box border is widened, the new interior
# strip shows the dark half-opaque scene-dim through it. Add these to the SAME
# matched line to paint a flat panel over that strip (menu text stays on top):
#   fillcol=0xRRGGBB  fillx=N filly=N fillw=N fillh=N  [fillsemi=1]
#   fillsemi=1 = semi-transparent (GP0 0x62) to match a translucent box; else opaque.
#   Tip: match a border tile of the target box (u/v + caller=/sig=), set fill* to the
#   interior rect in screen coords, F5 to reload and nudge the numbers live.
#
# Example - status label 'Zenny' at u=120 v=8, EN width 29, German needs 40:
#   u=120 v=8 w=40

# --- Field command box + submenus: widen/shift at the DRAW call (nav-safe) -------
# box_autofit hooks the 9-slice drawers (0x677B50 / 0x677E30) and rewrites the
# pushed args per CALLER:  width=  new pixel width ;  boxx= / boxy=  new (absolute)
# origin ;  dx= / dy=  RELATIVE nudge (dx=-30 = 30px left, dy=4 = 4px down) — the
# easy way to shift a box/cursor since the logged x is often garbage/animated.
# NOTE: dx/dy move the box FRAME + selection cursor only, NOT baked label text;
# to move a menu's label text too, that's a code-level shift (e.g. the equipment-
# skill "Menü" uses the equip_menu_shift config value, not dx here).
# The open-counter [state+6] (which also gates input) is NEVER touched, so
# navigation stays intact. Values below follow the German team's SGAMEN geometry
# (box width 0x5C=92, origin x=6/7). Live-reload with F5. Tune with the rect tuner.
#
# MAIN command box (Objekte/Spezial/Ausrüstung/Status/Wechseln), y=44:
caller=0x0067D01C width=92 boxx=6
#
# SUBMENUS (Benutzen/Sortieren/Entfernen/Wichtiges, Anlegen/Optimal/Ablegen, ...).
# Shift left to x=7 (German) and widen the multi-item boxes so the words fit:
caller=0x0067D20C width=75 boxx=7    # 4-item submenu (y=60)
caller=0x0067D59C width=75 boxx=7    # 4-item submenu (y=60)
caller=0x0067D34C width=75 boxx=7    # 3-item submenu (y=58)
caller=0x0067D47C width=75 boxx=7    # 3-item submenu (y=58)
caller=0x0067D89C boxx=7             # 2-item submenu (Wechseln: Normal/Kampf) — shift only
#
# TIME + ZENNY boxes (bottom-left, drawn by the other 9-slice drawer 0x677E30):
caller=0x0067D9E4 width=92 boxx=6    # Time box (y=169) — widen + shift left
caller=0x0067DB33 width=92 boxx=6    # Zenny box (y=192) — widen (low-word counter) + shift
#
# SUBMENU selection frames (highlight drawn by 0x6786D0). Widen to match the
# 75-wide submenu boxes (German: box-4). Their X follows the label automatically.
caller=0x0067D2EA width=71           # submenu sel-frame (box 0x67D20C)
caller=0x0067D415 width=71           # submenu sel-frame (box 0x67D34C)
caller=0x0067D53E width=71           # submenu sel-frame (box 0x67D47C)
caller=0x0067D65C width=71           # submenu sel-frame (box 0x67D59C)
#

# --- CAMP / TENT "Menü" box (Ausruhen/Speichern/Fähigkeit/Meister) ----------------
# Widen CLEANLY at the drawer (box_autofit), like the command menu — the engine
# tiles the whole 9-slice (border + fill + dark interior) at any width. Three drawer
# callers: settled box + open/close animation. Settled caller from the tile chain
# (0x677C9C -> 0x4B0C23). All -> width 122.
caller=0x004B0C23 width=70          # SETTLED box drawer caller
caller=0x004B0A16 width=70          # open animation
caller=0x004B0DD7 width=70          # close animation
# Selection cursor: drawn by 0x6786D0 (same drawer as the command cursor), called
# from 0x4B0D97. arg2 = width (computed here, literal push 0x47 in the command menu);
# box_autofit overrides arg2 regardless. width ~= box - 6.
caller=0x004B0D97 width=64            # selection cursor — tune with F5
